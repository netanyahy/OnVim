**OnVim** — современный, быстрый и эргономичный форк Vim в стиле LazyVim со встроенным менеджером плагинов, встроенной поддержкой LSP (Python, JavaScript/TypeScript, Java), всплывающим меню команд и эстетичной графитовой темой.

---

## ✨ Особенности

* 📦 **Встроенный менеджер плагинов (OnVim Plug):** Никаких ручных установок утилит через curl — менеджер плагинов уже встроен в OnVim. Добавляйте `Plug 'user/repo'` в свой `init` файл.
* ⚙️ **Простой конфиг `.init` без Lua:** Конфигурация в понятном декларативном формате (`~/.config/onvim/init` или `~/.init`).
* 🎨 **Эстетичный темный стиль:** Глубокая серо-графитовая палитра (Charcoal / Monochrome), никакого лишнего синего цвета.
* 📂 **Проводник файлов (VS Code Sidebar):** Боковая панель файлов с иконками, открывается и закрывается по `Ctrl + B` или `<leader>e`.
* ⚡ **Всплывающее меню команд:** При нажатии `:` и `Tab` над командной строкой появляется всплывающее popup-меню.
* 🚀 **LSP & Автодополнение на лету:**
  * **Python:** `pyright` (полное автодополнение, подсказки типов, документация)
  * **JavaScript / TypeScript:** `typescript-language-server`
  * **Java:** `eclipse-jdtls`
  * Мгновенный popup вариантов при вводе и переключение по `Tab` / `Shift+Tab`.
* 📑 **Вкладки сверху (Bufferline):** Удобные вкладки открытых файлов с номерами и индикатором изменений.
* 📊 **Статус-лайн:** Стильный Airline в монохромных тонах.
* 🔁 **Вечная история отмен (Persistent Undo):** История отмен `u` сохраняется даже после закрытия файлов.

## 🚀 Быстрая установка

```bash
git clone https://github.com/netanyahy/onvim.git
cd onvim
chmod +X install.sh
./install.sh
```

После завершения запустите:
```bash
onvim
```

## ⌨️ Горячие клавиши

Клавиша **`<Leader>`** — `Пробел`.

| Сочетание клавиш | Действие |
| --- | --- |
| `Ctrl + B` или `<leader>e` | Открыть / скрыть проводник файлов (NERDTree) |
| `Ctrl + S` или `<leader>w` | Быстро сохранить файл |
| `<leader>q` | Выход |
| `Tab` / `Shift + Tab` | Следующий / предыдущий открытый файл (вкладка) |
| `Ctrl + H / J / K / L` | Перемещение между сплитами (окнами) |
| `<leader>v` / `<leader>s` | Вертикальный / горизонтальный сплит |
| `<leader>x` | Закрыть текущий сплит |
| `J` / `K` (в Visual mode) | Перемещение выделенных строк вниз / вверх |
| `<` / `>` (в Visual mode) | Сдвиг отступа с сохранением выделения |
| `gcc` | Закомментировать / раскомментировать строку |
| `Escape` | Сбросить подсветку поиска |

### LSP (Language Server Protocol)

| Клавиша | Действие |
| --- | --- |
| `gd` | Перейти к определению (Go to Definition) |
| `gr` | Найти все ссылки и использования (References) |
| `K` | Всплывающая подсказка с документацией (Hover Doc) |
| `<leader>rn` | Переименование переменной по проекту (Rename) |
| `[d` / `]d` | Предыдущая / следующая ошибка линтера |
| `<leader>f` | Форматирование кода |
